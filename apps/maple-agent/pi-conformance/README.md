# Pi reference harness

This test-only flake executes TypeScript Pi `v1.0.4` at
`7c10bd4337495ee613f2224843ecdf349b80d1df`. It is separate from the Agent
product flake and does not add Node to the product toolchain.

The initial spike installs Pi's exact npm lockfile with `importNpmLock`,
hydrates the model catalog using its upstream SHA-256 pin, and executes
source modules through Pi's Vitest configuration. Dependency and catalog
downloads are fixed-output Nix fetches. No provider account is used.

From `apps/maple-agent`:

```sh
nix build ./pi-conformance#spike -L --no-link --no-update-lock-file
```

`spike` combines these independently reproducible checks:

- `upstream-tests` runs `agent-loop`, `agent`, `session-context-edit`, and
  `extensions-runner`. Its output includes raw Vitest list and result
  reports with task locations.
- `corpus` records `agent/basic-text-turn` twice and requires a byte-for-byte
  match. Each run uses a fixed clock, seeded randomness, explicit faux
  provider identity, and fixed chunk sizes. Events and provider requests
  are snapshotted at delivery, before upstream objects can mutate again.

The aggregate output also records the exact Node version and catalog size.
The raw upstream reports contain build paths and timings and are diagnostic
spike artifacts, not the eventual committed conformance inventory.
Vitest's `list --json` omits skipped tests. The complete inventory must use
its collector and include skipped cases from all three selected packages.

## Initial scope

The spike covers four upstream suites and one recorder scenario. It does
not yet implement the Rust crates, the full scenario interpreter, the
complete test inventory, or the coverage gate. A successful macOS run does
not establish the required x86_64 Linux sandbox result.

The corpus is generated by the reference recorder. Do not edit generated
records by hand. Pi's MIT license is reproduced in `LICENSE`.
